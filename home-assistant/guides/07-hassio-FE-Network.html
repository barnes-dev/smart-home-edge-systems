Expanded description

The compute architecture separates the primary LAN from an isolated backend segment for Home Assistant and supporting services. The wider system includes Pi-hole with Unbound, Nginx Proxy Manager, and a Twingate connector. This guide will explain how those network services are represented and monitored in Home Assistant without assuming details absent from the source documents.
